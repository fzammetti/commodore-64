# commodore-64
A few VERY old Commodore-64 related things

* D64Viewer - a D64 file viewer class in C that I wrote a long time ago while working on the PocketHobbit project (the first fully functional C64 emulator port to the PocketPC platform).

* C64Colors.htm - a stupid little HTML thing I did to emulate the classic C64 color cycling effect.

* c64-conversions - this contains AI-aided (who am I kidding: completely AI-done!) conversions of some of my C64 stuff (demos, intros, apps, etc.) to Phaser.
