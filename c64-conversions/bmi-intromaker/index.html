    About this reconstruction

    BMI Intromaker 1 is an intro, the intro editor that made it, and the linker that joined them, all on one disk. SPACE in the intro starts the editor. There you can type both scroll texts and three title lines, save the intro to the virtual disk and run the compactor. Its own instructions page explains the linking steps. Files saved on the disk can be downloaded and run on a real C64 or in an emulator.

    The intro, the KERNAL screen editor the BMI editor relies on, and the compactor are translated to JavaScript. Each was checked against the original 6502 code. The compactor produces the same packed file as the C64 does.

    Timing is NTSC: 65 cycles × 263 lines, about 59.83 frames per second. Test intro, the disk panel and faster disk transfers are browser additions. SID sound is an approximation and starts after your first interaction. Analysis and fidelity notes.
