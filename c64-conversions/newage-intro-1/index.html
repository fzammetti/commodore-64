About this reconstruction

The intro Fantasy wrote for NewAge's release of Genius (April 1988), reconstructed from the supplied Commodore 64 program. The original character set, logo, texts, scroll text and music are preserved. Phaser presents JavaScript translations of the recovered main loop, raster interrupts and music player.

As on the C64, any key leaves the intro: it clears the screen, resets the C64 and copies the game into place. The game itself is not part of this reconstruction, so it stops on the blue screen where Genius would start. Like the original, the exit sometimes hangs on a black screen. A key or R then runs the intro again.

Sound starts after your first interaction. Animation follows NTSC timing and 263 raster lines, with every raster bar and colour store placed at the cycle VICE runs it. One cleanup: the border bars and the logo's wobble change only between lines, which removes the split side bars and stray pixels the original shows. The SID sound is an approximation. The browser controls are additions.
