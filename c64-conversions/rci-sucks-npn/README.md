# RCI Sucks — NPN

Phaser reconstruction of Fantasy of NPN's Commodore 64 demo RCI Sucks. It includes the opening and all six sections,
original character graphics, sprite patterns, bitmap, messages, and five recovered SID tracks.
The browser runs native JavaScript models, without a C64 emulator.

SPACE advances, 1–5 select Shocwave's bounce patterns, R restarts a section,
M toggles sound, P pauses, F enters fullscreen, and F1 returns to the opening.
The opening waits for its curtain to finish before accepting SPACE. The browser's
Next part button skips it immediately. Sound starts after interaction.

Timing uses **NTSC: 1,022,730 Hz, 65 cycles × 263 lines, about 59.826 frames/s**.
The final letter uses the original NTSC CIA timer for its color changes.
